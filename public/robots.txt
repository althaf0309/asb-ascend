# HOW THIS FILE WORKS (the part that is easy to get wrong):
# A crawler obeys exactly ONE group - the most specific one matching its name -
# and ignores every other group, including "User-agent: *". So a named group
# that only says "Allow: /" hands that crawler the admin area as well.
# Every group below therefore repeats the same Disallow rules.
#
# Consecutive User-agent lines share the rule block that follows them, which is
# why the crawlers are grouped by purpose rather than listed one by one.
