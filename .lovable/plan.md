

# ASB Training Hub — Premium EdTech Website

## Overview
Build a world-class, conversion-focused training institute website with 14 pages, 50+ course listings, premium glassmorphism UI, smooth animations, and strong lead generation features.

## Design System
- **Colors**: Dark navy (#0F172A) + electric blue (#3B82F6) + violet (#8B5CF6) + white, with gradient accents
- **Style**: Glassmorphism cards, soft shadows, gradient sections, parallax backgrounds
- **Typography**: Bold modern headings, clean body text
- **Animations**: Scroll reveal, animated counters, hover effects, floating elements

## Phase 1 — Core Layout & Home Page
- **Sticky navbar** with mega menu for course categories (ERP, Programming, AI, Management, Internships)
- **WhatsApp floating button** (sticky, bottom-right, links to +91 8714773304)
- **Premium footer** with quick links, contact info, social links, newsletter signup
- **Home page sections**:
  - Full-screen hero with animated headline "Transform Your Career with Industry-Focused Training", gradient overlay, CTA buttons (Explore Courses, WhatsApp Now)
  - Animated trust stats (students trained, programs, career support, practical sessions)
  - Featured course categories with 3D-inspired cards
  - Why Choose ASB Training Hub (icon cards with hover effects)
  - Popular courses slider
  - Internship + placement support banner
  - Student testimonial cards with ratings
  - FAQ preview accordion
  - Contact CTA section with inquiry form

## Phase 2 — About & Contact Pages
- **About Us**: Institute story, mission/vision, timeline journey section, trainer quality, career-focused model, Trivandrum presence
- **Contact Us**: Address, Google Map embed, phone, email, WhatsApp button, inquiry form, office visit CTA

## Phase 3 — Courses Infrastructure
- **Courses listing page** with search, category filters/tabs, stylish cards (image, title, description, duration, mode, internship badge, CTA)
- **Individual course detail page template** with hero banner, overview, who should join, syllabus highlights, tools covered, career opportunities, internship/project options, certification info, FAQ, inquiry form, WhatsApp CTA, related courses
- **Category pages**: ERP/SAP (13 courses), Programming (12 courses), AI Trainings (9 courses), Management (7 courses), Internship Programs (10 courses)

## Phase 4 — Engagement Pages
- **Student Success / Reviews**: Testimonial cards with profile images, ratings, career outcomes, transformation stories
- **Gallery**: Image grid with lightbox, categories (classroom, events, certifications)
- **FAQ**: Full accordion page organized by topic
- **Blog / Career Insights**: Blog card grid with featured post, categories, read more links
- **Apply Now / Enquiry**: Multi-field lead capture form with course selection, callback request, WhatsApp CTA

## Phase 5 — Polish & Optimization
- Scroll reveal animations on all sections
- Animated counters with intersection observer
- Parallax sections
- Mobile-first responsive refinements
- SEO meta tags, semantic HTML, schema-friendly course structure
- Performance optimization

## Key Features
- All 51 courses with detailed data across 5 categories
- Lead capture forms on every page
- WhatsApp integration throughout
- Glassmorphism UI with gradient backgrounds
- Smooth page transitions and hover interactions
- Fully responsive (desktop, tablet, mobile)
